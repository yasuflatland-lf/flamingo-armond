# Supabase module

Provisions the Supabase project and writes auth configuration (Site URL,
redirect allow list, Google OAuth provider). Splitting `supabase_project` and
`supabase_settings` into separate resources keeps the loopback dependency from
Vercel acyclic in the Terraform DAG.

## Inputs

| Name | Description |
|---|---|
| `project_name` | Display name for the project. |
| `organization_id` | Owning Supabase organization. |
| `region` | Region slug (e.g. `ap-northeast-1`). |
| `google_oauth_client_id` | Google OAuth client ID. |
| `google_oauth_client_secret` | Google OAuth client secret (sensitive). |
| `site_url` | Auth Site URL (typically the Vercel production domain). |
| `redirect_urls` | Allowed redirect URLs. |

## Outputs

| Name | Description |
|---|---|
| `project_ref` | Project slug used in `https://<ref>.supabase.co`. |
| `project_url` | Full base URL. |
| `anon_key` | Public-safe API key (sensitive in state). |
| `db_url` | Session-mode pooler DSN. |
| `db_password` | Generated DB password (sensitive). |
| `jwks_url`, `jwt_issuer`, `jwt_audience` | JWT validation values for backend. |

## Notes

- `supabase_project` carries `lifecycle { prevent_destroy = true }`. Removing
  the project drops its database. Disable the guard explicitly to destroy.
- The DB password is generated by `random_password`. Rotation is `terraform
  taint random_password.db && terraform apply`.
